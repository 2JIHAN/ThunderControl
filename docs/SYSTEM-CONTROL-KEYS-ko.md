# 밝기와 음량 기능 키

0.8.30.28부터 양쪽 Mac의 인증된 입력 hello에서 `systemControlKeyCodec=1`을 확인하면 다음 macOS 기능 키를 전달한다.

- 음량 올리기, 내리기, 음소거
- 밝기 올리기, 내리기

일반 F1/F2/F11/F12 입력은 기존 일반 키 경로 그대로다. 미디어 기능으로 입력될 때는 `systemDefined` 타입14, subtype8을 엄격히 검사한다. 전원과 재생 등 다른 시스템 키는 허용하지 않는다. 일반 이벤트 허용 목록에 타입14를 통째로 추가하지 않는다.

## 안전 경계

송신은 기존 인증 연결, 원격 소유권, 화면 전환과 포커스 검사를 따른다. 상대가 지원하지 않으면 전송하지 않는다. 수신은 타입, subtype, 코드, 누름/반복/뗌 상태를 검증하고 새 이벤트를 만든다. 전송된 기타 시스템 이벤트 필드를 OS에 그대로 재생하지 않는다. Shift와 Option 미세 조절만 보존하며, 이 제한된 플래그를 전체 키보드 상태로 간주해 Ctrl 등 기존 보조 키를 해제하지 않는다.

송신과 수신에 최대 5개의 기능 키 상태만 유지한다. 수신은 먼저 누르지 않은 키의 반복이나 해제를 거부한다. 연결 종료에는 실제 주입한 키만 해제한다. 송신에서 억제한 키가 연결 종료 뒤 물리적으로 떼어지면 기존 orphan 관리가 로컬 유출을 막는다. 화면 전환 일시 정지는 기능 키 상태도 초기화하되 기존 복귀 의도를 보존한다. 종료나 권한 상실로 이벤트 탭 자체가 사라지면 OS 수준 필터링을 보장할 수 없다는 기존 제약은 같다.

## 검증과 한계

191개 코덱/상태 검사, 실제 CGEvent 직렬화/복원, 암호화 메시지와 호환성 검사, 실제 수신 함수의 주입 대체 경로, 키 해제 경로와 보조 키 보존을 검사했다. 합성 이벤트와 테스트 대체 출력은 실제 두 Mac의 키 입력이나 물리 장치의 변화 증거가 아니다.

대상 Mac이 디스플레이 밝기 또는 오디오 출력 음량 조절을 macOS 기능 키로 지원해야 실제 값이 바뀐다. 임의 외부 모니터의 DDC 밝기 제어를 추가한 기능이 아니다. 사용자 설정과 페어링, Keychain, Thunderbolt 전용 연결 정책은 바꾸지 않는다.
